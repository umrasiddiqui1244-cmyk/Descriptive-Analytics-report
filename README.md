# IBM Cognos Analytics Practicals – RetailPulse

## Project Overview
This repository contains Practical 1, Practical 2, and Practical 6 performed using IBM Cognos Analytics. These practicals focus on data analysis, report creation, and customer insights visualization using RetailPulse data.

## Tools Required
- IBM Cognos Analytics
- RetailPulse Dataset / Data Module
- Web Browser

## Practical 1: Introduction to IBM Cognos Analytics
**Objective:** To understand the basic features of IBM Cognos Analytics and explore the available RetailPulse data.

**Description:**
- Opened IBM Cognos Analytics.
- Explored the available data and data modules.
- Learned the basic interface and reporting features.
- Understood how data can be used for analysis and visualization.

**Outcome:** Learned the basic interface of IBM Cognos Analytics and how to access data for reporting.

## Practical 2: Create a RetailPulse Sales List Report
**Objective:** To create a list report using RetailPulse sales data.

**Description:**
- Opened the RetailPulse sales data source.
- Created a new list report.
- Added relevant sales fields to the report.
- Arranged the fields in a tabular format.
- Ran the report to view the sales records.

**Outcome:** Created a RetailPulse Sales list report to display sales information in a structured format.

## Practical 6: Build the RetailPulse Customer Insights Dashboard
**Objective:** To create a dashboard that provides insights into RetailPulse customer data.

**Description:**
- Created a new dashboard in IBM Cognos Analytics.
- Connected the RetailPulse Customers data module.
- Added a summary card to display total active customers.
- Created a line chart to show new and returning customers over time.
- Created a bar chart to compare customers by loyalty segment.
- Added a Region filter to analyze data for different regions.
- Arranged and saved the dashboard.

**Outcome:** Created a customer insights dashboard with visualizations and a Region filter for interactive analysis.

## Conclusion
These practicals helped develop basic skills in IBM Cognos Analytics, including data exploration, report creation, filtering, and dashboard visualization. They demonstrate how business data can be presented in a clear and meaningful way.
